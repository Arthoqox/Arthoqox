### `whoami`

```text
arthoqox@hiddenode:~$ status

ROLE       builder of automation, network tooling and calm interfaces
MISSION    hide the complexity — expose the control
CURRENT    HiDDENODE
SIGNAL     curious / shipping / always refining
```

I turn complicated infrastructure into tools that feel simple. My work lives at the intersection of **automation**, **network services**, **Telegram-first products**, and the small details that make software pleasant to operate.

### ◈ Now transmitting

- Building **HiDDENODE** — an opinionated control layer for private access infrastructure
- Designing admin flows that stay fast when the system gets complicated
- Automating the boring parts: provisioning, lifecycle, observability and recovery
- Exploring AI-assisted operations without giving up human control

</td>
<td width="50%" valign="top">

### ◇ Operating principles

- **Quiet by default** — the best infrastructure disappears into the background
- **Observable by design** — invisible systems still need visible truth
- **Secure in layers** — no single point should carry all the trust
- **Built to recover** — failure handling is part of the product
