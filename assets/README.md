# Profile assets

`terminal-hero.svg` is the primary code-native profile interface.

`system-map.svg` is the supporting capability map. Both assets are original SVG interfaces designed for the Arthoqox profile and remain sharp at any GitHub viewport size.

`telemetry.svg` and `signal-daemon.svg` are local, dependency-free replacements for externally hosted statistics and contribution widgets.

`engineering-surface.svg` replaces narrow Markdown tables with a responsive four-module interface that scales without horizontal scrolling.
